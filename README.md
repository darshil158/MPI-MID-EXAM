# 🚀 MPI Exam Master — 8085 Microprocessor & Interfacing

> A focused, exam-oriented interactive study website for GTU Semester 5  
> **Microprocessor and Interfacing — BE05000551**

---

## 📚 Project Overview

**MPI Exam Master** is a lightweight, responsive, single-page study application designed specifically for preparing the GTU Mid-Term examination.

The website organizes the syllabus into:

- 📖 Complete exam-oriented topics
- ⭐ Priority levels
- 📝 Full 8-mark answers
- 💻 8085 assembly programs
- 📊 Architecture and bus explanations
- 🔁 Previous/Next topic navigation
- 🔎 Topic search
- 🎯 Priority filtering
- 📈 Study progress tracking
- 🌙 Dark mode
- 🎯 Focus mode
- 🎲 Random topic practice
- 📱 Mobile responsive layout

The application works completely on the client side.

No backend or database is required.

# 🧠 Study Strategy

The website is designed around an **8-mark answer strategy**.

For each important topic, try to remember:

1. Definition
2. Introduction
3. Main concept
4. Architecture / diagram / flowchart
5. Detailed explanation
6. Example
7. Advantages / applications where relevant
8. Important exam points

For programming questions:

1. Problem statement
2. Algorithm
3. Assembly program
4. Instruction explanation
5. Expected result / working

# ⭐ Priority System

Topics are assigned priority levels to help with limited preparation time.

### 🔴 High Priority

Topics that should be prepared first.

Focus on:

- Architecture
- Buses
- Pin functions
- Instruction cycle
- Machine cycles
- Assembly programming
- Decision making
- Looping
- Stack
- Subroutines
- Delay routines
- BCD arithmetic
- 16-bit operations

### 🟠 Medium Priority

Important supporting concepts that should be prepared after high-priority topics.

### 🟢 Low Priority

Useful for complete preparation and revision.
